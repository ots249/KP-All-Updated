# Master Class - Diploma Educational Platform 🎓

ডিপ্লোমা ইন ইঞ্জিনিয়ারিং শিক্ষার্থীদের পড়াশোনাকে আরও সহজ এবং আনন্দদায়ক করার জন্য তৈরি একটি আধুনিক ও ইন্টারেক্টিভ লার্নিং অ্যাপ্লিকেশন। এটি একটি **Next-Generation PWA (Progressive Web App)** যা মোবাইল এবং ডেস্কটপ উভয় ডিভাইসেই চমৎকার অভিজ্ঞতা প্রদান করে।

---

## ✨ বিশেষ ফিচারসমূহ (Key Features)

### ১. ইন্টারেক্টিভ সোয়াইপ গেসচার (Swipe Interactions)
- **লেকচার সোয়াইপ**: প্রতিটি ক্লাসের আইটেমকে ডানদিকে সোয়াইপ করে 'ফেভারিট' এবং বামদিকে সোয়াইপ করে 'সম্পন্ন (Complete)' হিসেবে চিহ্নিত করা যায়।
- **ব্যানার সোয়াইপ**: কোর্সের উপরের মেইন ব্যানারটি সোয়াইপ করে সহজেই এক সাবজেক্ট থেকে অন্য সাবজেক্টে সুইচ করা যায়।

### ২. অটো লাইভ ক্লাস ডিটেকশন (Live Class Integration)
- অ্যাপটি স্বয়ংক্রিয়ভাবে চেক করে কোনো লাইভ ক্লাস চলছে কিনা।
- লাইভ ক্লাস থাকলে সেটি সরাসরি কোর্সের ব্যানারে ভিডিও প্লেয়ার হিসেবে ওপেন হয়, ফলে শিক্ষার্থীদের অ্যাপের ভেতরেই লাইভ ক্লাসে যুক্ত হওয়া সহজ হয়।

### ৩. অফলাইন সাপোর্ট ও ডাউনলোড (Offline Capabilities)
- অফলাইন থাকলেও আপনি আপনার আগে থেকে লোড হওয়া ডেটা দেখতে পারবেন।
- **PDF ডাউনলোড**: প্রতিটি পিডিএফ ফাইলের পাশে ডেডিকেটেড ডাউনলোড বাটন রয়েছে যা অফলাইন ব্যবহারের জন্য ফাইল সেভ করতে সাহায্য করে।

### ৪. স্মার্ট সার্চ ও হাইলাইটিং (Smart Search)
- সার্চ বক্সে কিছু লিখলে তাৎক্ষণিকভাবে পুরো কোর্সের লেকচার এবং অধ্যায়ের টাইটেল থেকে ম্যাচিং টেক্সট হাইলাইট করে দেখানো হয়।

### ৫. প্রোগ্রেস ট্র্যাকিং (Learning Progress)
- আপনার কতটুকু পড়াশোনা শেষ হয়েছে তা রিয়েল-টাইমে প্রোগ্রেস বারের মাধ্যমে ট্র্যাক করা যায়। 
- অধ্যায় ভিত্তিক এবং কোর্স ভিত্তিক আলাদা আলাদা প্রোগ্রেস রিপোর্ট।

### ৬. প্রিমিয়াম ইউজার ইন্টারফেস (UI/UX)
- **Splash Screen**: অ্যাপটি ওপেন হওয়ার সময় একটি চমৎকার গ্রাফিক এনিমেশন দেখায়।
- **ডার্ক/লাইট মোড**: আপনার চোখের আরাম অনুযায়ী থিম পরিবর্তন করার সুবিধা। এটি সিস্টেম ডিফল্ট থিমের সাথেও অটো-সিঙ্ক করে।
- **টেলউইন্ড ডিজাইন**: ক্লিন এবং মডার্ন ডিজাইন যা ইউজারদের পড়াশোনায় মনোযোগ বাড়াতে সাহায্য করে।

## 🛠 প্রযুক্তিগত টুলস (Technologies Used)

- **Frontend**: React 18+ with TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Motion (formerly Framer Motion)
- **Icons**: Lucide React
- **State Management**: React Hooks (useMemo, useEffect, useState)
- **Routing**: React Router DOM

## 📖 ব্যবহারের নিয়মাবলি ও নির্দেশিকা (Usage Rules)

1. **ইন্সটলেশন**: মোবাইল ইউজাররা ব্রাউজারের 'Add to Home Screen' বা অ্যাপের ভেতর থাকা 'Install' বাটন ব্যবহার করে এটি অ্যাপ হিসেবে সেটআপ করতে পারবেন।
2. **লেকচার ভিউ**: যেকোনো লেকচার আইটেমে ক্লিক করলে যদি সেটি ভিডিও হয় তবে একটি প্রিমিয়াম ইউটিউব প্লেয়ারে ওপেন হবে, আর পিডিএফ হলে সেটি কাস্টম পিডিএফ ভিউয়ারে ওপেন হবে।
3. **সার্চ অপশন**: কোনো নির্দিষ্ট টপিক খুঁজে পেতে উপরের সার্চ আইকন ব্যবহার করুন।
4. **অফলাইন সতর্কতা**: অফলাইন মোডে থাকাকালীন ভিডিও প্লে হবে না, তবে ডাউনলোড করা পিডিএফ ফাইল এবং টেক্সট কন্টেন্ট দেখা যাবে।
